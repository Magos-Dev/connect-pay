# Connect Pay

Plataforma de análise e gestão de crédito.

## Publicação
Envie `index.html` para a pasta pública do subdomínio configurado na Hostinger.
Configure o Supabase conforme a interface e valide autenticação e RLS antes de usar dados reais.

## Segurança
Não publique `.env.local`, senhas, tokens nem chaves secretas. O `.env.example` é apenas um modelo.

Consulte `BRIEFING.md`, `AUDITORIA.md` e `CHANGELOG.md`.
